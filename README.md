# 🚀 WordQuest – เรียนอังกฤษสนุก ฟรี 100%

เว็บเรียนคำศัพท์และไวยากรณ์ภาษาอังกฤษแบบเกม ไม่มีโฆษณา ไม่ต้องสมัคร

## มีอะไรบ้าง
- 📖 คำศัพท์ 750 คำ: CEFR A1–C2 และ IELTS Band 4.0–8.0 (ระดับละ 50 คำ) พร้อมเสียงอ่าน
- 🃏 Flashcards · ❓ ตอบคำถาม 5 แบบ · 📝 ข้อสอบจำลองจับเวลา
- 🧠 คลังทบทวนคำที่ตอบผิดบ่อย (ทบทวนตามรอบ 1 → 3 → 7 วัน)
- 📰 Reading แนว IELTS 6 ชุด พร้อมเฉลยภาษาไทย
- 📘 ไวยากรณ์ 18 บท (A1–C1) 108 ข้อ
- 🎮 XP, แรงก์, คอมโบ, เหรียญรางวัล, เป้ารายวัน

## วิธีใช้
เปิดเว็บที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` หรือดาวน์โหลดแล้วเปิด `index.html`

ความคืบหน้าเก็บไว้ในเบราว์เซอร์ ถ้าจะย้ายเครื่อง ให้กด "💾 สำรองความคืบหน้า" ท้ายหน้าแรก

## เพิ่มเนื้อหา
- คำศัพท์: `data-extra.js` (ประโยคตัวอย่างต้องมีคำศัพท์รูปเดิมแค่ครั้งเดียว)
- ไวยากรณ์: `grammar.js`
- Reading: `reading.js`

กด F12 แล้วดูแท็บ Console ระบบจะตรวจข้อมูลให้อัตโนมัติ
